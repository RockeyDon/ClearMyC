# ClearMyC

[English](README.md) | 中文

我的C盘又满了！我（加上大模型）知道该清理哪些目录 —— 我只是需要个【一键删除】工具。

一款轻量级、独立运行的 Windows 10 桌面应用，用于发现和清理占用磁盘空间的目录。可选集成 LLM，自动识别可安全删除的文件夹（缓存、临时文件、构建产物、旧日志等）。

所有配置本地存储在 `./clear_my_c.json` 中。

## 功能特性

**手动清理**
- 添加需要监控和清理的目录
- 一目了然地查看实时文件夹大小（启动时自动扫描）
- 通过复选框选择/取消选择文件夹
- 移至回收站（可恢复）或彻底删除
- 两种删除模式均有确认对话框

**LLM 驱动的自动发现**
- 连接任何 OpenAI 兼容的 LLM API（本地或远程）
- BFS 扫描驱动器，按可配置的策略规则过滤，然后询问 LLM 哪些目录可以安全删除
- 发现的文件夹自动添加——LLM 推荐的预选中，其他保持未选中供您审查

**策略配置**
- **跳过列表**：分号分隔的路径，永不触碰（如 `C:\Windows;C:\Program Files`）
- **最小大小**：忽略小于此阈值的目录
- **跳过最近**：忽略在 N 天内修改过的目录

**多语言支持**
- 在设置 > 主题页面切换语言

**其他**
- 浅色 / 深色 / 跟随系统主题
- API 密钥在配置文件中加密存储（AES-128-CBC）
- 便携式单文件——直接运行即可

## 快速开始

### 下载

前往 [Releases](https://github.com/RockeyDon/ClearMyC/releases) 页面，下载最新的 `clear_my_c.exe`，直接运行——无需安装。

### 从源码构建

如果您更喜欢自行构建：

```bash
# 前提条件：Windows 10 + Rust 工具链（MSVC 目标）
cargo build --release
./target/release/clear_my_c.exe
```

### LLM 设置（可选）

1. 打开设置（⚙️ 按钮）
2. 进入 **策略** 标签页
3. 填写您的 LLM API 信息：
   - **接口地址**：您的 OpenAI 兼容 API 端点（如 `https://api.openai.com/v1`）
   - **模型**：模型名称（如 `gpt-4`）
   - **密钥**：您的 API 密钥
4. 点击 **连接测试** 验证连接
5. 返回 **文件夹** 标签页，点击 **自动发现**
